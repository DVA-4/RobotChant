## `firmware/07j_pacing/standardDict.cpp`

The 1,427-word dictionary from Mike McCauley's
[SpeakJet library for Arduino](https://www.airspayce.com/mikem/arduino/SpeakJet/),
Copyright (C) 2011 Mike McCauley, licensed under the **GNU GPL version 2**.
McCauley generated it with his `convertDict.pl` from Sensory's `PhraseALator.Dic`.

**Modified for this project** (the pronunciation data is untouched):
the include was changed from `<SpeakJet.h>` to `"dict.h"`, the type name
`SpeakJet::DictionaryEntry` to `DictionaryEntry`, and a stray `extern` on an
initialised definition was removed.

Because this file is GPL v2, the firmware as a whole is distributed under GPL v2.

## `firmware/07j_pacing/extradict.h`, sections 2–5

Generated by `tools/dic2extradict.py` from Sensory's `PhraseALator.Dic`, the
dictionary shipped with Sensory's Phrase-A-Lator software for the SpeakJet. The
translation follows the rules of the original Phrase-A-Lator as re-implemented in
[benbaker76/PhraseALator](https://github.com/benbaker76/PhraseALator).
`PhraseALator.Dic` itself is **not** included in this repository.

Section 1 of the file is original work.

## `firmware/07j_pacing/bigdict.cpp`, `bigdict.h`

Generated by `tools/cmu2bigdict.py`. The pronunciations are derived from the
[CMU Pronouncing Dictionary](https://github.com/cmusphinx/cmudict), whose licence
requires the notice below. The words were chosen using the frequency ranking of
[wordfreq](https://github.com/rspeer/wordfreq) (Apache-2.0), which the tool uses
at generation time and which is not redistributed here. The conversion model is
trained on the Sensory data in `standardDict.cpp`.
